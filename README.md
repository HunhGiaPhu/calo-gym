# Calo Gym

App cá nhân (PWA) theo dõi calo và lịch tập gym. Dữ liệu lưu trên máy (IndexedDB), không cần server.

```bash
npm install
npm run dev      # chạy thử
npm test         # test hàm tính toán
npm run build    # build ra dist/
```

Nhập lại danh sách món từ Excel: `python -I scripts/import_foods.py "<file.xlsx>"`
